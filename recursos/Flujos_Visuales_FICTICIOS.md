# Esquemas visuales de formación
No representan instalaciones o procedimientos aprobados de Mazana.

## Logística
Pedido -> validar familia, toneladas y destino -> revisar capacidad y restricciones -> proponer carga -> confirmar con el responsable -> entregar -> registrar incidencia y evidencia.
Carriles: animales, pienso y cereal. Si falta un dato, el flujo vuelve a revisión.

## Pienso
Recepción de materia prima -> revisión documental y muestreo según procedimiento aprobado -> almacenamiento identificado -> dosificación y mezcla -> acondicionamiento si procede -> expedición y trazabilidad.
No se aportan recetas, temperaturas, tiempos, dosis ni límites críticos. No inventarlos.
